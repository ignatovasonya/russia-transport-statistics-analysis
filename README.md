# Анализ статистики транспорта России

## Описание проекта
Статистический анализ показателей транспортной системы Российской Федерации за период 2005–2024 гг.

## Цель исследования
Изучение динамики основных транспортных показателей и выявление долгосрочных тенденций развития транспортной инфраструктуры России.

## Данные

Источник:
официальные статистические данные Российской Федерации

Период анализа:
2005–2024 гг.

Показатели:
- грузооборот транспорта
- пассажирооборот
- объем перевозок грузов
- перевозки пассажиров
- протяженность автомобильных дорог
- длина железнодорожных путей

## Используемые инструменты

- Python
- pandas
- matplotlib
- Jupyter Notebook
